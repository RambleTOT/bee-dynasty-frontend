# Расхождения спеки и API

Сверка `docs/spec/FRONTEND_SPEC.md` (v2.2) и живой схемы `https://api.bee-dynasty.ru/openapi.json` (`src/api/schema.d.ts`). Пополняется по мере работы; снимки ответов — `docs/api-examples/`.

## 28.09 — этап 01 (каркас), по схеме
