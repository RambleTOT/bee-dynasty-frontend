**Допущения [Д] экрана инженера:**

- текущая заявка: `active_request_id`, иначе первая `planned`; заявка в пути или в работе без `active_request_id` — тоже текущая (бэк не даст начать другую);
- визиты с незнакомым статусом не показываем; `shift_status` не пришёл — по визитам (что-то тронуто → «на смене»);
- в карточке адрес без «Город Москва, », но с квартирой (как в макете); в строках — без города и квартиры;
- «Прервать выполнение»: по умолчанию выбрано «Клиент отказался» (как в макете); «Желаемая дата» — от даты дня инженера;
- плашка про автомобиль в E-02 — если выбран не справочный транспорт и не автомобиль;
- «Не выйду сегодня»: подсказки «Текущую заявку доделайте…» нет (до смены текущей заявки нет);
- карточка заявки: подписи «ЖДЁТ РЕШЕНИЯ · N ИЗ M» и «ЗАВЕРШЁННАЯ · N ИЗ M» для ждущей и закрытой; «Выполнить задачу» из карточки ведёт к списку;
- «Завершить смену» с оставшимися заявками — подтверждение шторкой `?sheet=shift_end`;
- «Начато в окне» в итогах — «{started_in_window} из {done}»; «Прервано» без `shift_totals` — ждущие решения, отменённые и перенесённые;
- номер на маркере карты — `sequence`, как в кружках списка.
