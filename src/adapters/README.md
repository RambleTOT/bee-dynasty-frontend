# src/adapters — модели экранов из ответов API

**Правило:** компоненты работают только с моделями адаптеров, а не с сырым API. Всё, где API расходится с макетами, — здесь: склейка ответов, безопасный доступ к полям «без схемы» (`?.`, значения по умолчанию), запасные подписи. Каждый адаптер — с юнит-тестами на фикстурах из `docs/api-examples`.

## Будущие адаптеры (FRONTEND_SPEC §6)

| Файл             | Что делает                                                                  |
| ---------------- | --------------------------------------------------------------------------- |
| `dayModel.ts`    | склейка плана, заявок и инженеров дня (§6.1)                                |
| `constraints.ts` | три ограничения в карточке заявки: «Квалификация», «Время», «Ресурс» (§6.2) |
| `compare.ts`     | три колонки сравнения: наш / базовый FIFO / реальный диспетчер (§6.3)       |
| `proposal.ts`    | событие → предложение с diff (§6.4)                                         |
| `feed.ts`        | лента дня (§6.5)                                                            |
| `geo.ts`         | геометрия карты (§6.6)                                                      |
| `normalize.ts`   | синтетические наборы: пустые поля, подписи, условные координаты (§6.8)      |
